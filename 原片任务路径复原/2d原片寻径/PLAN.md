# 《Episode 44》原片走法反推与方位术语验证方案

> 本文保留首轮后端反推实验的设计与参数。当前的贯通路线扫描与 2D 回放进展见[项目 README](../../README.md)。

---

## 一、 问题背景与目标

在《Episode 44》的二维截面（$z = 0$）场景中，场上存在 5 个三维球面探测波源（位于不同高度 $z_i$，按 $10\,\mathrm{m/s}$ 球面扩张，每隔 $10\,\mathrm{s}$ 发出一道新波峰）。人物从 $x$ 轴正半轴远处出发，以每次最多 $50\,\mathrm{m}$ 的瞬移方式向原点 $(0, 0)$ 推进，目标是抵达距原点 $50\,\mathrm{m}$ 以内的接应区域且全程不被任何探测波扫到。

根据原片剧情与口播提示：
1. **初期直行阶段**：在波场尚未密集叠加时，人物一直沿 $-x$ 轴以 `-50m` 步长直行推进。
2. **斜走指路阶段（前段，1 ~ 7 步）**：当五个波源的波峰开始在 $x$ 轴前方密集叠加后，原片给出了一组以“一号位 / 左二 / 右二 / 左三 / 右三”描述的躲避指令（共 8 跳）：
   - 第 1 步：`左三，43 m`
   - 第 2 步：`一号位，50 m`
   - 第 3 步：`左三，45 m`
   - 第 4 步：`右三，30 m`
   - 第 5 步：`右三，47 m`
   - 第 6 步：`左三，40 m`
   - 第 7 步：`一号位，各 30 m 二段跳，两秒间隔`（即第一跳 $30\,\mathrm{m}$ 落地后等待 $2.0\,\mathrm{s}$，再跳第二跳 $30\,\mathrm{m}$）
3. **剧情掐断与末段收尾（最后 5 步）**：中间部分跳跃被剪辑跳过，最后 5 步指令为：
   - `左二，53 m` $\to$ `右二，40 m` $\to$ `一号位，20 m` $\to$ `左二，30 m` $\to$ `右二，45 m`（最终落入距原点 $\le 50\,\mathrm{m}$ 范围内）。

**核心目标**：在完全不知道初始起点 $x_0$ 与切入时刻的前提下，通过大量自动化实验验证，反推出原片所采用的**参考坐标系（动态更新 vs 恒定不变）**、**“二 / 三”对应的真实偏转角度**，以及能够无碰撞走通上述指令的**典型起点范围与时间表**。

## 二、 已锁定的物理与时间规则

### 1. 波场模型
- 直接复用 [`wave-field.js`](../../波源立体几何重建/2d/wave-field.js) 中的 5 源实测参数（`SOURCES`）。
- **传播上限**：`maxRadius = Infinity`（探测波无限向外扩散，不截断）。

### 2. 洞口生命周期与安全裕度
- **洞半径与安全要求**：每个洞为半径 `holeRadius = 1.0 m` 的圆，且任意活跃洞边缘与任意波环的距离必须满足 **`safetyMargin >= 1.0 m`**（即圆心到波环的距离 $|d - r(t)| \ge 2.0\,\mathrm{m}$）。
- **单跳时间线**：
  - `tOpen`：在当前旧洞 `A` 开启新洞 `B`，`A` 与 `B` 同时进入可探测状态。
  - `tArrive = tOpen + 0.5 s`：人物完全进入新洞 `B`。
  - `tExpire_A = tArrive + 1.0 s = tOpen + 1.5 s`：人物完全进入 `B` 后，旧洞 `A` 再保持 `1.0 s` 复原消失。
- **等待机制**：
  - 到达 `B` 后可等待任意 `waitTime >= 0 s`（等待期间 `B` 保持可探测），再开启下一个洞 `C`。
  - 唯一锁定：第 7 步二段跳之间固定 **`waitTime = 2.0 s`**。

### 3. 左右方位定义（已锁定）
- 以人物**面向原点**时的第一人称视角为准：
  - **左侧（左二 / 左三）**：人物左手边，即面向 $-x$ 时向 **$-y$ 方向**偏转（顺时针旋转 $-\theta$）。
  - **右侧（右二 / 右三）**：人物右手边，即面向 $-x$ 时向 **$+y$ 方向**偏转（逆时针旋转 $+\theta$）。

## 四、 后端实验与计算流程设计

### 1. 上游直行 + 自动遇波切入（`x0` 大范围扫描）
- 扫描初始起点 **`x0 ∈ [10000 m, 30000 m]`**，步长 **`200 m`**（共 101 个起点，覆盖 $10\text{–}30\,\mathrm{km}$ 级别的远距离出发场景，确保波场有充分时间多层叠加）。
- 从 `(x0, 0)` 在 `t = 0` 出发，沿 $-x$ 轴以 `-50 m / 0.5 s`（$100\,\mathrm{m/s}$）连续推进，并实时校验每一跳的安全性（`safetyMargin >= 1.0 m`）。
- **自动遇波切入**：当直行推进到某一步，发现“再往前直接 `-50 m` 会违反 `1.0 m` 安全裕度”时，自动停止直行并将该位置与时刻 `(x_branch, t_branch)` 作为切入点，进入前段 8 跳测试（同时可测试在遇波前最后 1~2 跳提前切入作为容错对照）。

### 2. 前段（1 ~ 7 步，8 跳）时间表搜索
- 给定 `(假说, x_branch, t_branch)` 后，前段 8 个落点坐标 $P_0 \to P_1 \to \dots \to P_8$ 唯一确定。
- 在每一步之间搜索等待时间 `waitTime ∈ [0, 4.0 s]`（步长 `0.25 s`，第 7 步两段跳锁定 `waitTime = 2.0 s`），借助 `isHoleSafeDuring` 解析检测判断是否存在无碰撞时间序列 $(t_0, \dots, t_7)$，并记录最大可达安全裕度 `minMargin`。

### 3. 末段（最后 5 步 + 终局 `r <= 50 m`）独立反推
- 因为中间剧情掐断，末段 5 步在极坐标 `(r_in, φ_in)` 网格上独立扫描（`r_in ∈ [100 m, 260 m]`，`φ_in ∈ [-90°, +90°]`）：
  - **几何过滤**：仅保留第 5 步落点满足 $\sqrt{x^2 + y^2} \le 50\,\mathrm{m}$ 的候选区域。
  - **时空验证**：在 `10 s` 波场周期内扫描进入末段的相位时刻 `t_end_in`，搜索 5 步无碰撞时间表并记录 `minMargin`。

### 4. 评价与判别指标
对 4 组假说分别输出汇总统计表：
1. **前段可行起点数 / 命中率**（在 101 个 `x0` 中有多少能走通前段 8 跳，以及最大 `minMargin`）。
2. **末段可行区域面积 / 命中率**（有多少 `(r_in, φ_in, t_end_in)` 能安全落入 `r <= 50 m`）。
3. **前后段几何衔接度**（前段终点 `P8` 是否朝末段合法区域收敛、距离与方位是否自洽）。

## 五、 目录规划与测试计划

在 `2d原片寻径/` 下按以下结构组织纯后端代码：
- `2d原片寻径/PLAN.md`：本方案文档。
- `2d原片寻径/canon-experiment.mjs`（或 `experiment.js`）：核心纯后端反推模块与批量扫描脚本，直接复用 [`wave-field.js`](../../波源立体几何重建/2d/wave-field.js)（`maxRadius: Infinity`）与 `../pathfinding/solver.js` 的解析碰撞检测 `isHoleSafeDuring` 及独立校验 `validatePath`。
- **测试验证项目**：
  1. **单元测试**：验证 4 组假说下坐标旋转公式（确保面向 $-x$ 时向左确实向 $-y$ 偏转）、第 7 步 `waitTime = 2.0 s` 锁定、旧洞 `tArrive + 1.0 s` 消失逻辑正确无误。
  2. **全量扫描运行**：执行批测脚本，打印 4 组假说在前段、末段的表现对比表，以及最优匹配解的逐跳坐标与时间表，并用 `validatePath` 做 `0.02 s` 步长的独立复核。
