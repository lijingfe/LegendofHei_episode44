# Episode 44 · 五源波场与路线复原

本项目从《罗小黑战记》第 44 集「冬冬拯救行动方案五」的视频帧反推探测波场，再尝试拼接原片中的瞬移路线。五个球面波源在 `z = 0` 平面上的交圆，是第二阶段寻径使用的动态障碍。

## 波源立体几何重建

已从二维画面校准比例尺，用多帧拟合和同源双圈法交叉估计五个波源的位置与首次发波时间，再参考三维侧视画面判断高度正负。仿真采用 **10 m/s** 波速和 **10 s** 发波周期，提供与原片 `f326` 俯视、`f425` 侧视相对应的参考机位。五色二维截面和寻径共用 `wave-field.js` 的波场模型。

## 原片任务路径复原

通用寻径器用时空 A* 在随时间变化的波场中搜索路径。新洞从开启起可被探测，旧洞在人物抵达下一洞后继续留存一段时间。算法检查每个洞的完整存续区间，要求终点进入原点周围 **50 m** 的接应圈。

原片回放把直行前奏、已知前九跳、剪辑省略的中段和已知末五跳接起来。当前前段包含「左二 46 m」，二段跳间隔设为 **0.4 s**，中段采用十二方向搜索。每条导出路线使用 **0.1 s** 的时间网格，按 **1 m** 洞半径和至少 **1 m** 的洞缘安全裕度做连续时间复核。

截至 **2026-11-23**，本地贯通实验以 **50 m** 步长扫描 **2,000–6,000 m** 的 81 个起点，共保存 **7,242 条**路线。

| 固定方位角（二号位 / 三号位） | 贯通路线数 |
| --- | ---: |
| ±60° / ±90° | 2,977 |
| ±45° / ±90° | 3,285 |
| ±30° / ±60° | 980 |

贯通路线验证了对应参数组合的可行性。原片实际采用的方位、洞口时序及被剪掉的中段仍未唯一确定。逐帧测量得到一次穿越约 **0.8 s**，按网格图白点的较长留存时间重测时，固定 `45° / 90°` 的末五跳扫描未找到可行解。

- [2D 原片寻径回放](./原片任务路径复原/2d原片寻径/viewer.html)支持按方位角、穿越耗时、旧洞留存和起点选解，逐跳定位开洞时刻。线上与本地回放均读取无损压缩的 `unified_paths.json.gz`。
- [通用 2D 寻径](./原片任务路径复原/2d_pathfinding/)支持自定义起点和安全裕度。算法及批测位于 [`pathfinding/`](./原片任务路径复原/pathfinding/)。
- [首轮方位假说实验方案](./原片任务路径复原/2d原片寻径/PLAN.md)、[扫描结果](./原片任务路径复原/2d原片寻径/results.json)和[时间参数重测报告](./原片任务路径复原/原片时间参数实测与H_fix_45_90重测报告.md)保留了早期参数与调试结论。[当前贯通路线生成脚本](./原片任务路径复原/2d原片寻径/build-unified-paths.mjs)记录了新版搜索规则。

## 本地运行与复核

在 `Episode44/` 根目录启动静态服务，然后打开 [本地首页](http://127.0.0.1:8080/)。3D 页面通过 CDN 加载 Three.js。

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

用 Node.js 运行已有测试及导出数据复核。

```sh
node '波源立体几何重建/2d/test-field.mjs'
node '原片任务路径复原/pathfinding/verify.mjs'
node '原片任务路径复原/2d原片寻径/test-experiment.mjs'
node '原片任务路径复原/2d原片寻径/build-unified-paths.mjs' --verify
```
