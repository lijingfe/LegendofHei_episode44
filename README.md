## 核心技术亮点

1. **零构建纯原生 ES Module**：所有网页均采用原生 HTML + CSS + ES Module（CDN `importmap` 引入 Three.js / KaTeX），推送到 GitHub 后在仓库 **Settings → Pages → Build and deployment** 中选择当前分支根目录即可直接上线为常驻网站。
2. **前后端解耦的物理碰撞内核（`2d/wave-field.js`）**：纯数学模块，零 DOM 依赖，同时支持浏览器与 Node.js 调用。
3. **解析碰撞 + 时空 A\* 寻径（`pathfinding/solver.js`）**：
   - 利用静止洞圆与单调扩张波环的解析交集公式实现 $O(1)$ 精确碰撞判断（支持 `0.5s` 瞬移到达、旧洞 `1.0s` 延迟消失、任意等待时间以及大 `xStart` 远端快速直行优化）。
   - 内置 `0.02s` 步长的独立全时空复核函数 `validatePath`，确保规划路径 100% 安全可行。
