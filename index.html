Episode 44 · 五源波场与路线复原

从《罗小黑战记》第 44 集的画面重建探测波，再检验小黑能否按已知口令进入原点周围 50 米的接应圈。

波源立体几何重建

已从视频帧反推五个波源的位置和发波时间，用俯视与侧视参考帧核对 3D 仿真，并生成 z = 0 的二维截面供寻径使用。

3D 动画还原蓝色经纬网、相贯切线与原片参考机位 五色 3D 球面波观察五个波源的传播与平面切面 五色 2D 波场交圆时间轴、距离探针与碰撞提示 波源反推计算比例尺校准、两种高度估算和逐源结果

原片任务路径复原

按原片已知的前九跳和末五跳约束路径，搜索剪辑省略的中段，并检查每个洞口的存续时间。最新数据包含 7,242 条贯通路线，覆盖三组固定方位角和 2,000–6,000 米的起点扫描。原片实际采用的参数和中段走法仍未唯一确定。

2D 原片寻径回放预计算路线，可切换方位角、洞口时间和起点 通用 2D 避障寻径自由设置起点和裕度，实时计算并逐跳回放 时间参数实测逐帧测量穿越、等待和白点留存时间
